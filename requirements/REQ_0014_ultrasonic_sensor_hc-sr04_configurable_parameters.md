**ID**: REQ_0014

**Status**: In specification

**Type**: Functional

**Description**:<br>
The project shall use ultrasonic sensors of type hc-sr04 for obstacle detection.

Following configurable parameters shall be defined:
- SENSOR_TRIGGER_PIN
- SENSOR_TRIGGER_PIN_LOW_TIME_MICROSECONDS, default 5
- SENSOR_TRIGGER_PIN_HIGH_TIME_MICROSECONDS, default 10
- SENSOR_ECHO_PIN
- SPEED_OF_SOUND_MILLIMETER_PER_MICROSECOND
- DISTANCE_THRESHOLD_MILLIMETER
