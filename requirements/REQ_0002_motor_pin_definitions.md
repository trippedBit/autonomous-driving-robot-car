**ID**: REQ_0002

**Description**:<br>
The following pin definitions shall be used.

| Pin name | Description |
| -- | -- |
| ENA_PIN | PWM pin for motor 1 |
| FORWARD1_PIN | When set to high and BACKWARD1_PIN is low in the same time, motor 1 rotation direction is forward. |
| BACKWARD1_PIN | When set to high and FORWARD1_PIN is low in the same time, motor 1 rotation direction is backward. |
| ENB_PIN | PWM pin for motor 2 |
| FORWARD2_PIN | When set to high and BACKWARD2_PIN is low in the same time, motor 2 rotation direction is forward. |
| BACKWARD2_PIN | When set to high and FORWARD2_PIN is low in the same time, motor 2 rotation direction is backward. |
