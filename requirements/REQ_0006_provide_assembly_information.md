**ID**: REQ_0006

**Status**: In specification

**Type**: Non-Functional

**Description**:<br>
An assembly information shall be provided with the repository.<br>
The information shall contain detailed information how to assemble the robot as needed for this project.

To do so, the information shall refer to the BOM which is also provided with the repository and shall contain for each step:
- Unique part number
- Part name
- Description how to add the part to the project
